> 日期：2026-11-10　|　对应规划：`Unity体素_阶段3_数据管线规划.md`
> 结论：**第一版已跑通并装到真机**——PC 离线数据 → 手机只读格式 → 场景渲染，手机实测 **60fps / 49 chunk / 29.8 万顶点**。

## 1. 管线

```
Minecraft 存档 (.mca)
      │  vxtool.py build（PC 离线，Python 标准库，28 s / 841 chunk）
      ▼
Assets/StreamingAssets/vxworld/  world.manifest.json + blocks.json + cells/*.vxcell（3.85 MB）
      │  VoxelWorld（StreamingAssets 异步读 + Deflate 解压 + 位解包）
      ▼
ChunkMesher（隐藏面剔除 + y 窗口裁剪 + 顶点色）── 每 chunk 一个 Mesh + GameObject
```

手机/编辑器都不解析 NBT；网格化在运行时做，改地图数据不用重打包。

## 3. 工具

`E:\unity\Projects\VoxelGeoVR\Tools\vxworld\vxtool.py`（源：workspace `voxel_stage3/tool/`）

```bash
python vxtool.py scan     --world "<存档>"
python vxtool.py build    --world "<存档>" --out "<输出>" --band 8
python vxtool.py validate --dir "<输出>"
python vxtool.py dump     --dir "<输出>" --chunk 0,0 --y 62
```

格式 v1（小端）见规划 §4.5：cell = 8×8 chunk；header 32 B + deflate(payload)；chunk = `minSectionY/sectionCount/topY[256]/sections`；section 三模式（全空气 / 全同方块 / 局部调色板位压缩）。

## 6. 踩过的坑（都已修）

| 现象 | 原因 | 处理 |
|---|---|---|
| `UnityWebRequest` 不存在 | manifest 缺 `com.unity.modules.unitywebrequest` | 补模块包 |
| Package Manager 报 `Non-whitespace before {` | PowerShell 写 UTF-8 带 BOM | `UTF8Encoding(false)` 重写 |
| 中文脚本乱码 / 换行被吞 | PowerShell 默认编码 + 文本替换 | 改用文件写入工具重写源码 |
| 镜头跑到地图外/地下 | `TeleportToSpawn` 直接改子相机世界坐标，留下巨大局部偏移 | 移动根节点 + 相机 localPosition 归零 |
| 树冠/悬崖变悬空薄片 | 按列 `top-8` 裁剪把树下的地面切掉 | 改按 chunk 的 y 窗口 `[min(top)-8+1, max(top)]` |
| 整体发白 | Linear 色彩空间 + 顶点色直接吃 sRGB | 调色板 sRGB→Linear |
| 湖是黑洞 | 水 `solid=false` 不参与网格化 | 水改实心 |
| 手机 30fps | Unity 移动端默认锁 30 | `targetFrameRate=60` + `vSyncCount=0` |
| 出生点贴着树干 | MC 出生点随机长树 | 工具算 `spawnView` 开阔点 |

## 7. 已知问题 / 下一版

1. 水面不透明（无深浅/波纹），无花草/藤蔓（`solid=false` 全部不渲染）。
2. chunk 边界不做邻块剔除（被埋的面不可见，约 5% 冗余）。
3. 远景 LOD 未接（数据已带 `topY`），半径固定 4。
4. HUD 是 IMGUI 调试面板。
5. 移动/陀螺仪只验证了按钮在屏，未做长时漫游手感测试。

> 已接受、不修：HUD 显示的相机 y 比 `spawnView.y` 高约 7；画面高度正常、不影响观感与漫游，按现有结论冻结。
